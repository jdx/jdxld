# Project governance

jdxld is maintained by [Jeff Dickey](https://github.com/jdx). Changes are developed through GitHub
pull requests in [jdx/jdxld](https://github.com/jdx/jdxld).

This repository retains the history and attribution of the upstream
[Wild](https://github.com/wild-linker/wild) project. Wild's maintainers and governance do not govern
this fork unless they separately choose to participate here.

The governance policy will be expanded if the project adds maintainers or begins accepting broader
community contributions.
